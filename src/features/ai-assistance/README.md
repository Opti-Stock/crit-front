# Asistencia al historial

El panel común se usa dentro de notas médicas y notas de enlace. Permite solicitar
un resumen persistente, hacer preguntas independientes, navegar a fuentes y
registrar feedback.

El frontend hace polling solo para trabajos iniciados en la pantalla actual. Las
respuestas sin evidencia muestran `Información insuficiente`. Ninguna acción
copia texto de IA al expediente y siempre permanece visible la advertencia de
verificación.
